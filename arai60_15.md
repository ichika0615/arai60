# Step 1
## hashmapに要素(キー)、登場したインデックス(バリュー)を格納。前から操作すれば一番初めのunique characterが見つかる。
```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        character_to_frequency = defaultdict(list)
        for index, character in enumerate(s):
            character_to_frequency[character].append(index)

        for _, indecies in character_to_frequency.items():
            if len(indecies) == 1:
                return indecies[0]
        return
```
- 時間計算量: O(n) 空間計算量: O(n)
- 100ms くらいで実行可能と概算。
- n番目に登場するunique character出して、と言われた時にしんどい。

## 2回目登場した時に、データ構造から消去して、残ったものはuniqueであるはず。
## ↓動かない。
```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        unique_to_index = defaultdict(int)
        for index, character in enumerate(s):
            if character in unique_to_index:
                del unique_to_index[character]
            else:
                unique_to_index[character] = index

        unique_indeces = [index for _, index in unique_to_index.items()]
        if len(unique_indeces) != 0:
            return unique_indeces[0]
        else:
            return -1
```
- よく考えたら奇数回登場するやつは辞書に復活するのでダメ。
