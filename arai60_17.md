### DFS
```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        def mark_island_as_visietd(i, j):
            if not (0 <= i < column_length and 0 <= j < row_length):
                return 
            if grid[i][j] == '0':
                return
            grid[i][j] = '0'
            mark_island_as_visietd(i-1, j)
            mark_island_as_visietd(i+1, j)
            mark_island_as_visietd(i, j-1)
            mark_island_as_visietd(i, j+1)
        
        number_of_islands = 0
        column_length = len(grid)
        row_length = len(grid[0])
        for i in range(column_length):
            for j in range(row_length):
                if grid[i][j] == '1':
                    number_of_islands += 1
                    mark_island_as_visietd(i, j)
        
        return　number_of_islands         
```
- 入力に対して破壊的で、場合にもよるが好ましくない。
- ```row_length = len(grid[0])```の0はマジックナンバーか。
- 再帰呼び出しのオーバーヘッドは、最大で(全部陸地)
- 時間計算量: $O(M*N)$ (M、Nをそれぞれ縦横の長さとする)
- 空間計算量: $O(1)$
- ChatGPTと話していたら、DFSだと言われて驚いた。DFSはグラフとセットで使うと思っていたが、「行けるところまで行く」戦略を定式化したものなのかもしれない。

## BFS
```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        def remove_islands(colum, row):
            lands = deque([(colum, row)])
            while lands:
                column, row = lands.popleft()
                if not (0 <= column < column_length and 0 <= row < row_length):
                    continue 
                if grid[column][row] == '0':
                    continue
                grid[column][row] = '0'
                directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
                for di_c, di_r in directions:
                    lands.append((column + di_c, row + di_r))
        
        column_length = len(grid)
        row_length = len(grid[0])
        number_of_islands = 0
        for i in range(column_length):
            for j in range(row_length):
                if grid[i][j] == '1':
                    number_of_islands += 1
                    remove_islands(i, j)
        
        return number_of_islands
```
- 時間計算量$O(M*N)$  空間計算量$O(1)$
- 正直DFSとBFSの違いがよくわからない。どちらも「行けるところまで行く」戦略に従っているように見える。

    def __init__(self, size):

    def find(self, node):
        root = node
        while self.parents[root] != root:
            root = self.parents[root]

        root_2 = self.find(node_2)
