## BFS
```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        nodes_to_visit = deque([(root, 1)])
        while nodes_to_visit:
            node, depth = nodes_to_visit.popleft()
            if not node.left and not node.right:
                return depth
            if node.left:
                nodes_to_visit.append((node.left, depth + 1))
            if node.right:
                nodes_to_visit.append((node.right, depth + 1))
        
```
- 一段ずつ見ていって、葉っぱを見つけ次第そこが一番浅い深さ。
- 時間計算量: O(N) (0.1sくらい)
- 空間計算量: O(N)
## DFS
```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        nodes_to_visit = [(root, 1)] # This is a stack.
        MAX_DEPTH = 10**5
        min_depth = MAX_DEPTH
        while nodes_to_visit:
            node, depth = nodes_to_visit.pop()
            if not node.left and not node.right:
                min_depth = min(min_depth, depth)
            if node.left:
                nodes_to_visit.append((node.left, depth + 1))
            if node.right:
                nodes_to_visit.append((node.right, depth + 1))
        
        return min_depth
```
- 時間計算量: O(N)
- 空間計算量: O(N)
- 計算量の求め方がよくわからなかった。BTでは高さは最大Nだからこのようにしたが、最悪計算量であって、平均計算量がある気がする。
- DFSではガンガン最深部まで進んで、後から戻って、、、を繰り返す。-> min_depthを用意して更新する必要がある。

- BFSは幅優先なので、一段ずつ丁寧に深めて探索する。今回はBFSの方が直感的だと感じた。
- `if not root`のところはValueErrorを吐いても構わないと思う。
