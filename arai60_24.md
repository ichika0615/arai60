## DFS
- stackを用いてDFS
```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        root = TreeNode()
        node_left_right = [(root, 0, len(nums) - 1)]

        while node_left_right:
            node, left_index, right_index = node_left_right.pop()
            middle_index = (left_index + right_index) // 2
            node.val = nums[middle_index]
            if left_index < middle_index:
                node.left = TreeNode()
                node_left_right.append((node.left, left_index, middle_index - 1))
            if middle_index < right_index:
                node.right = TreeNode()
                node_left_right.append((node.right, middle_index + 1, right_index))

        return root
```
- そのまま再帰に直した。引数に両端を入れたかったのでhelperを作って再帰。
- リストをスライスするのはスライスされた要素数をkとするとO(k)かかるので、境界を格納した方が処理は早い。
```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def sorted_array_to_bst_helper(node, left, right):
            middle = (left + right) // 2
            node.val = nums[middle]
            if left < middle:
                node.left = TreeNode()
                sorted_array_to_bst_helper(node.left, left, middle - 1)
            if middle < right:
                node.right = TreeNode()
                sorted_array_to_bst_helper(node.right, middle + 1, right)
            
            return node
    
        root = TreeNode()
        return sorted_array_to_bst_helper(root, 0, len(nums) - 1)
```
- 両端は閉区間にするのが好き。leftが絶対閉じるのでrightも閉じててほしい。
- 時間計算量: O()
- 再帰深さはlogn。つまり最大14ぐらい？

## BFS
```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        
        root = TreeNode()
        node_nums_pairs = deque([(root, nums)])
        while node_nums_pairs:
            node, nums_list = node_nums_pairs.popleft()
            middle_index = len(nums_list) // 2
            middle_value = nums_list[middle_index]
            node.val = middle_value
            nums_on_left = nums_list[:middle_index]
            nums_on_right = nums_list[middle_index + 1:]
            if nums_on_left:
                node.left = TreeNode()
                node_nums_pairs.append((node.left, nums_on_left))
            if nums_on_right:
                node.right = TreeNode()
                node_nums_pairs.append((node.right, nums_on_right))
        
        return root
```
- 両端に注目する方法と、そうじゃなくてリストにそのまま着目する方法がある。リストの方はスライスしてシャローコピーしていけば良い。

## 非再帰
```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        
        root = TreeNode()
        left_right_node = [(0, len(nums) - 1, root)]
        while left_right_node:
            left, right, node = left_right_node.pop()
            middle = (left + right) // 2
            node.val = nums[middle]
            if left < middle:
                node.left = TreeNode()
                left_right_node.append((left, middle - 1, node.left))
            if middle < right:
                node.right = TreeNode()
                left_right_node.append((middle + 1, right, node.right))
        
        return root
```
