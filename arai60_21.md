# Step 1
- BFSで探索できれば最後まで行けば答えを出してくれると思い、BFSでの実装を考えた。
- BFSでは難しい。深さごとにノード数の上限が決まっているが、いつ下の階層に移動したかを検知する機構が思いつかない。
- 普通に再帰で行けた。
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```
- 時間計算量: O(N) 
- 空間計算量: O(N) 
- DFSと言われてピンとこなかった。確かに深く潜ってるしDFSかも、くらいの認識しか持てない。

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        current_depth_nodes = deque([root])
        depth = 0
        while current_depth_nodes:
            next_depth_nodes = deque([])

                    next_depth_nodes.append(node.left)

```

## 非再帰DFS
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        nodes_and_depth = [(root, 1)]  # This is a stack.
        max_depth = 1
        while nodes_and_depth:
            node, depth = nodes_and_depth.pop()
            max_depth = max(max_depth, depth)
            if node.left:
                nodes_and_depth.append((node.left, depth + 1))
            if node.right:
                nodes_and_depth.append((node.right, depth + 1))
        
        return max_depth
```

```python
class Solution:

        depth = 1

        while nodes_to_visit:
            length_of_the_depth = len(nodes_to_visit)

                node = nodes_to_visit.popleft()
                if node.left:
                    nodes_to_visit.append(node.left)
                if node.right:
                    nodes_to_visit.append(node.right)
            if not nodes_to_visit:
                break
            depth += 1
        
        return depth
```

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        current_level_nodes = [root]
        depth = 1
        while current_level_nodes:
            next_level_nodes = []
            for node in current_level_nodes:
                if node.left:
                    next_level_nodes.append(node.left)
                if node.right:
                    next_level_nodes.append(node.right)
            current_level_nodes = next_level_nodes
            if not current_level_nodes:
                break
            depth += 1
        
        return depth
```
- いずれにせよ、木構造を想像して、ある階層を右から左に横に走査して、depthを加算して下の階層に移動する。
- この実装は今いる階層を`current_level_nodes`、１つ下(遷移先)の階層を`next_level_nodes`として、```current_level_nodess = next_level_nodes```で下の階層に移っているので、本質的に同じことをしていると理解した。

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        nodes_to_visit = [(root, 1)]  # This is a stack.
        depth = 1
        max_depth = 0
        while nodes_to_visit:
            present_node, present_depth = nodes_to_visit.pop()
            max_depth = max(max_depth, present_depth)
            if present_node.left:
                nodes_to_visit.append((present_node.left, present_depth + 1))
            if present_node.right:
                nodes_to_visit.append((present_node.right, present_depth + 1))

        return max_depth
```
- DFSは最深部までガンガン進んだ後上に戻っていくので、`max_depth`で記録上の最大深さを記憶する必要がある。
- どうでもいいが、試しにappendメソッドの実装をCpythonで見てみたら(ChatGPTに解説させたりして)、なんかスレッドセーフが保証されてる場合とされてない場合で場合分けしていて、やってることは言うほど難しくなかった。あーそうなんですねーみたいな感想。
