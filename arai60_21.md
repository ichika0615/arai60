# Step 1
- BFSで探索できれば最後まで行けば答えを出してくれると思い、BFSでの実装を考えた。
- BFSでは難しい。深さごとにノード数の上限が決まっているが、いつ下の階層に移動したかを検知する機構が思いつかない。
- 普通に再帰で行けた。
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```
- 時間計算量: O(N) 
- 空間計算量: O(N) 

# Step 2
他の方の解き方も見ていく。
## BFS
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        current_depth_nodes = deque([root])
        depth = 0
        while current_depth_nodes:
            next_depth_nodes = deque([])
            for node in current_depth_nodes:
                if node.left:
                    next_depth_nodes.append(node.left)
                if node.right:
                    next_depth_nodes.append(node.right)
            current_depth_nodes = next_depth_nodes
            depth += 1
        
        return depth
```
- からっぽになった後に最後一回インクリメントするので、最初`depth = 0`と初期化しているのが非直感的で気に入らない。
- (追記)あー、まぁ、処理終わってからインクリメントしてる気持ちなら許容なのか。
## BFS(改良版)
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        current_depth_nodes = deque([root])
        depth = 1
        while 1:
            next_depth_nodes = deque([])
            for node in current_depth_nodes:
                if node.left:
                    next_depth_nodes.append(node.left)
                if node.right:
                    next_depth_nodes.append(node.right)
            current_depth_nodes = next_depth_nodes
            if not current_depth_nodes:
                break
            depth += 1
        
        return depth
```
- 綺麗になった。
## 非再帰DFS
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        nodes_and_indeces = [(root, 1)]  # This is a stack.
        max_depth = 1
        while nodes_and_indeces:
            node, depth = nodes_and_indeces.pop()
            max_depth = max(max_depth, depth)
            if node.left:
                nodes_and_indeces.append((node.left, depth + 1))
            if node.right:
                nodes_and_indeces.append((node.right, depth + 1))
        
        return max_depth
            
```
