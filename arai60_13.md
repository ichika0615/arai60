```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        found_in_nums1 = set()
        found_in_nums2 = set()

        for num1 in nums1:
            found_in_nums1.add(num1)
        
        for num2 in nums2:
            found_in_nums2.add(num2)
        
        return [value for value in found_in_nums1 & found_in_nums2]
```


```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        intersection = set()
        for num1 in nums1:
            if num1 in nums2:
                intersection.add(num1)
        
        return [value for value in intersection]
```
