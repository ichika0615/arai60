class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        intersection = set()
        for num1 in nums1:
            if num1 in nums2:
                intersection.add(num1)
        
        return [value for value in intersection]

## 別のシチュエーションを考えてみる。
- https://github.com/katataku/leetcode/pull/12#discussion_r1893968021
- 『片方がとても大きくて、片方がとても小さいときには、大きい方を set にするのは大変じゃないでしょうか、特に大きいほうが sort済みのときにはどうしますか』
- 大きい方がソート済みなら、小さい方だけ見ていきたい。
```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1.sort()
        common_numbers = set()
        for num2 in nums2:
            for num1 in nums1:
                if num2 == num1:
                    common_numbers.add(num2)
                elif num1 > num2:
                    break
    
        return [number for number in common_numbers]
```
- nums1の方が長かったと仮定して実装。
- 時間計算量: $O(nm)$ 空間計算量: $O(n)$
- 絶対にバイナリサーチの方が良い。後日実装します。
