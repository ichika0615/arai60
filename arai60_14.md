# Step 1
## ２つの条件(.を除外する/+以降は無視する)をそれぞれ関数に切り出して、emailsの値１つ１つに関数を作用させて、セットに格納。長さを出力すれば良い。
```python
class Solution:
    def numUniqueEmails(self, emails: List[str]) -> int:
        def remove_dot(address):
            address_list = []
            for i in range(len(address)):
                if address[i] == '.':
                    continue
                if address[i] == '@':
                    atmark_index = i
                    break
                address_list.append(address[i])
            for i in range(atmark_index, len(address)):
              address_list.append(address[i])

            return ''.join(address_list)

        def ignore_plus(address):
            address_list = list(address)
            plus_index = None
            for i in range(len(address_list)):
                if address_list[i] == '+':
                    plus_index = i
                    break
                if address_list[i] == '@':
                    break
            if plus_index:
                for i in range(len(address_list)):
                    if address_list[i] == '@':
                        atmark_index = i
                        break
                revised_address_list = address_list[:plus_index] + address_list[atmark_index:]
                return ''.join(revised_address_list)
            return address

        received_emails = set()
        for email in emails:
            dot_removed = remove_dot(email)
            revised_email = ignore_plus(dot_removed)
            received_emails.add(revised_email)

        return len(received_emails)
        
```
-　ここで使った、あまりよく分かっていない処理をドキュメントで確認した。
- len()はsys.maxsize以上の長さのシーケンスを受け取るとOverFlowErrorを投げる。
- CPythonの実装を確認したが、そもそもC言語が読めず、オーバーライドなどの理解できていない概念が出てきて難儀した。いつか読めるようになりたい。ただ、__len__というメソッドを呼び出しているぽい。
- join()は引数のイテレータにnon-stringが混じっているとTypeErrorを投げる。
- range()はステップが0ならValueError

## emailをルールに沿ってcanonicalizeしてセットに入れて、最後に長さをみる。
```python
class Solution:
    def numUniqueEmails(self, emails: List[str]) -> int:
        def canonicalize_email(email):
            canonicalized = []  # join to get str later 
            local_name = email.split('@')[0]
            host_name = email.split('@')[1]

            for character in local_name:
                if character == '+':
                    break
                if character == '.':
                    continue
                canonicalized.append(character)

            canonicalized.append('@')
            canonicalized.extend(host_name)
            return ''.join(canonicalized)

        original_emails = set()
        for email in emails:
            original_emails.add(canonicalize_email(email))
        
        return len(original_emails)

```
- 最近は処理を関数に切り出してメインの見通しをよくするのが好み。
- split(sep=None, maxsplit=-1)について、sepは複数文字でも良い。指定のない場合は空白をセパレータとする。
