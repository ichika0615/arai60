# Step 1 
## ランレンクスエンコーディングでまとめる。文字列をランレンクスエンコードして、それをキーとする。バリューには対応する文字列を格納する。

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def run_length_encoding(word):
            character_to_count = {}
            for word_item in word:
                character_to_count.setdefault(word_item, 0)
                character_to_count[word_item] += 1
            sorted_character_to_count = sorted(character_to_count.items())
            run_length = ''
            for character, count in sorted_character_to_count:
                run_length = run_length + character + str(count)
            return run_length

        
        group = defaultdict(list)
        for strs_item in strs:
            group[run_length_encoding(strs_item)].append(strs_item)
        
        return [words for _, words in group.items()]
```
- 正直二度と書くモチベが湧かない。

## ハッシュ値をキーにする。バリューには対応する文字列を格納する。
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def convert_to_hash(string):
            number = 0
            for string_item in string:
                number += ord(string_item) - ord('a') + 1
            return number
        
        string_to_hashes = defaultdict(list)
        for strs_item in strs:
            string_to_hashes[convert_to_hash(strs_item)].append(strs_item)
        return list(string_to_hashes.values())
```
- 時間計算量: O(NK)(Nは要素の数。Kは要素の文字数の平均)
- 空間計算量: O(N)
- ["ac","d"] のケースで衝突した。
- https://docs.python.org/ja/3.13/library/functions.html#ord
文字一字に対してUnicodeコードポイントを返す。
- ハッシュ関数をごちゃごちゃと複雑にしたら動くとは思う。

## キーとして、アルファベットの出現頻度をタプルを用いる。
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def letter_frequency(word):
            num_letters = 26
            letter_to_frequency = [0] * num_letters
            for word_item in word:
                item_number = ord(word_item) - ord('a')
                letter_to_frequency[item_number] += 1
            return tuple(letter_to_frequency)
        
        frequency_to_strs = defaultdict(list)
        for strs_item in strs:
            frequency_to_strs[letter_frequency(strs_item)].append(strs_item)
        
        return [words for _, words in frequency_to_strs.items()]

```
- 時間計算量: O(NK)
- 空間計算量: O(N)
## ソートした文字列をキーとする。
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def sort_letters(word):
            listed_letters = list(word)
            listed_letters.sort()
            return ''.join(listed_letters)
        
        key_to_strs = defaultdict(list)
        for strs_item in strs:
            key_to_strs[sort_letters(strs_item)].append(strs_item)
        
        return [words for _, words in key_to_strs.items()]
```
- 時間計算量: O(NKlogK)
- 空間計算量: O(N)

## Step 3
### アルファベットの出現頻度をタプルで表して、それを辞書のキーとする。キーを元にまとめていって、バリューを出力する。エラーハンドリング付き。
```python
class Solution:
    def groupAnagrams(self, strs):
        def letter_frequency(word):
            num_letters = 26
            letter_to_frequency = [0] * num_letters
            for word_item in word:
                item_number = ord(word_item) - ord('a')
                if not (0 <= item_number <= 25):
                    raise ValueError('inappropriate input')
                letter_to_frequency[item_number] += 1
            return tuple(letter_to_frequency)

        try:
            frequency_to_strs = defaultdict(list)
            for strs_item in strs:
                frequency_to_strs[letter_frequency(strs_item)].append(strs_item)
            return list(frequency_to_strs.values())
        except ValueError as e:
            return e
```
### 文字列をソートしてキーとする。

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def sort_string(string):
            listed_string = list(string)
            sorted_listed_string = sorted(listed_string)
            return ''.join(sorted_listed_string)

        key_to_strs = defaultdict(list)
        for strs_item in strs:
            key_to_strs[sort_string(strs_item)].append(strs_item)
        return list(key_to_strs.values())
```
